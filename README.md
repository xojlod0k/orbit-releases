# Orbit — сборки

Готовые сборки Orbit, локального менеджера проектов и команд для Windows x64.
Исходный код хранится отдельно; здесь только релизы.

Скачайте последнюю версию на странице [Releases](https://github.com/xojlod0k/orbit-releases/releases/latest):

- `Orbit-Setup-<версия>.exe` — установщик. Установленный Orbit сам проверяет
  обновления и ставит их по кнопке «Обновить».
- `Orbit.exe` — переносимая версия без установки. Она только сообщает о новой
  версии; файл нужно заменить вручную.

Проекты и настройки хранятся в `%APPDATA%\Orbit` и сохраняются при обновлении.

Сборки пока не подписаны, поэтому Windows SmartScreen может предупредить о
неизвестном издателе: «Подробнее → Выполнить в любом случае».

Об уязвимостях сообщайте приватно через
[Security Advisories](https://github.com/xojlod0k/orbit-releases/security/advisories/new),
не в публичных Issues.
